# ruby

Full validation suite for Ruby 3.2 projects.

## Commands

| Command | Description |
|---------|-------------|
| `/ruby-validate` | Run bundle audit, RuboCop, and RSpec in sequence |

## Requirements

- Ruby 3.2
- `bundler-audit` gem (`gem install bundler-audit`)
- RuboCop configured in project (`bundle exec rubocop`)
- RSpec (`bundle exec rspec`)

## Install

```
/plugin install ruby@cc-plugins
```
